Predicting Student Performance with Julia

We did an in-depth analysis of student issues.

Project Overview

We built a predictive analytics web application using Python and Julia for the Backend and React and Typescript for the Frontend.

View on GitHub Live Demo

Overview

We built a predictive analytics web application using Python and Julia for the Backend and React and Typescript for the Frontend. The app will allow users to upload a CSV dataset, provide a choice of predictive models then train the selected model on the dataset, display evaluation metrics, and visualize the results with interactive plots, showing trends and predictions. This project showcases Julia’s strength in both data science and web development by combining machine learning, visualization and an accessible web interface

Problem and Motivation

Schools collect a lot of student data — attendance, homework completion, test scores, and more — but it’s often underused. This makes it difficult to identify students at risk of failing or dropping out.

Our Solution: Build a simple, user-friendly web app to upload student data and get predictions.

Impact: Flag at-risk students for timely support so that both teachers and students can intervene early with strategies.

Project Description

We built a predictive analytics web application using:

  • Backend: Python & Julia
  • Frontend: React & TypeScript

The app allows users to upload a CSV dataset, choose a predictive model, train it, display evaluation metrics, and visualize results interactively.

This project showcases Julia’s strength in data science and web development by combining machine learning, visualization, and an accessible interface.

Methodology

  1. Data Collection
    Gathered student performance datasets (CSV format). Attributes: student_id , attendance_rate, test_score, homework_completion, at_risk.

  2. Data Preprocessing (Python & Pandas)
    Loaded data, dropped missing or invalid rows, validated required columns, and separated features (X) and target (y).

  3. Model Development (Python – scikit-learn)
    Implemented:
    • Logistic Regression — binary classification
    • Decision Tree Classifier — interpretable model
    • Linear Regression — continuous prediction
    Used train_test_split and 5-fold cross-validation for reliability.

  4. Model Evaluation
    Metrics:
    • Accuracy, Precision, Recall, F1-Score (classification)
    • MSE, RMSE, MAE, R² (regression)
    Generated confusion matrices and distribution plots.

  5. Visualization (Matplotlib & Seaborn)
    Created heatmaps and actual vs. predicted plots. Converted plots to base64 for web display.

  6. Web Server Integration (Julia – server.jl)
    Used Genie.jl / HTTP.jl for backend routes. Accepted CSV uploads, called Python scripts (ml_models.py), and returned predictions, metrics, and plots.

  7. Frontend Development (React – App.tsx)
    Built upload interface for CSV files. Displayed metrics, risk categories, and charts dynamically.

  8. Testing & Validation
    Tested multiple student datasets, verified accuracy, visualization, and upload reliability.

  9. Deployment
    Deployed backend (Julia + Python). Connected frontend (React/Vite) to backend API at localhost:8000. Ensured full integration.

Technical Stack

Python Julia Typescript React Seaborn Matplotlib Scikit-learn Pandas NumPy
