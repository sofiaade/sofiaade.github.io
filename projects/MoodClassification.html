Mood Classification with Machine Learning

Using Python and related libraries like Scikit Learn, we developed machine-learning models using ANN, SVM, DT, and KNN to predict the class of object labels.

Project Overview

Using Python and related libraries like Scikit Learn, we developed machine-learning models using ANN, SVM, DT, and KNN to predict the class of object labels. The process involved data preprocessing, feature extraction, model training, and evaluation to determine the most effective classification approach

View on GitHub Live Demo

Overview

    To build an end-to-end ML pipeline that reads time-series lifestyle data and predicts mood states using a combination of machine learning algorithms:
  • SVM
  • Decision Tree
  • K-Nearest Neighbors
  • Artificial Neural Network
  • Random Forest
  • Voting Ensemble

Problem and Motivation

Schools collect a lot of student data — attendance, homework completion, test scores, and more — but it’s often underused. This makes it difficult to identify students at risk of failing or dropping out.

Description & Goal

Develop a machine learning application to classify human mood states from daily lifestyle metrics (steps, sleep, water intake) using ANN, SVM, DT, and K-NN.

  • ANN — tuned hidden layers and iterations
  • SVM — tuned C and kernel
  • Decision Tree — tuned max_depth
  • K-NN — k from 3–10
  • Random Forest — 100 estimators
  • Ensemble — VotingClassifier of all models

Performance Summary

Model Accuracy F1 (Macro)
                        SVM 0.464 0.4436
                        Decision Tree 0.448 0.4208
                        KNN 0.456 0.4263
                        ANN 0.432 0.4264
                        RandomForest 0.528 0.5221
                        Ensemble 0.576 0.5619

Dataset split: 60% train / 20% validation (GridSearchCV) / 20% test. Metrics: Accuracy, Precision, Recall, F1 (macro), Confusion Matrices, ROC-AUC for SVM and ANN.

Conclusion

The pipeline demonstrates modular, scalable steps: feature engineering, rebalancing, tuning, and ensemble learning to improve classification of mood states.

    How to Run

    3. Models will be saved in MODEL/saved_models/
    4. Visual outputs and evaluation metrics will appear in OUTPUT/
